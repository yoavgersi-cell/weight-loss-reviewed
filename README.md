# Weight Loss Reviewed

Static editorial review/comparison site for online weight-loss programs, deployed on Vercel.

**Live intent:** [weightlossreviewed.com](https://weightlossreviewed.com)

## How it works

All pages are **static HTML generated by `build.py`** and committed to the repo root.
Vercel ("Other" preset, root `./`) serves the files as-is — no build step runs on Vercel.
`vercel.json` enables clean URLs (`/reviews/embody` → `reviews/embody.html`).

## Editing content

Everything lives in data dicts at the top of `build.py`:

- `PROVIDERS` — profiles, editorial scores, bullets, highlights, pros/cons, sub-scores
- `PROVIDER_ORDER` — the ranking (list order = rank)
- `VERSUS` — head-to-head "battle" pages (each with a hand-written verdict)
- `ARTICLES` — long-tail guides (HTML bodies)

After any edit:

```bash
python3 build.py     # regenerates all .html + sitemap.xml + robots.txt
```

Then commit the regenerated HTML.

## ⚠️ Before / right after launch: affiliate links

Outbound CTAs come from `AFFILIATE_LINKS` in `build.py`. Placeholders are `"#"` —
**swap in your real affiliate/tracking URLs and rebuild:**

```python
AFFILIATE_LINKS = {
    "embody":   "https://...",   # ← your link
    "ro":       "https://ro.co", # (real homepage placeholder)
    "altarex":  "https://...",   # ← your link
    "trimarex": "https://...",   # ← your link
    "bmimd":    "https://...",   # ← your link
}
```

Real affiliate links auto-render with `rel="sponsored nofollow"`.

## Content design notes

- **Different from treatmentshub.com by design:** the home page is a lean *comparison
  chart* (3 bullets + highlight + score + CTA per row), not content-heavy cards.
- Pricing is shown as a **relative tier ($–$$$)**, not fabricated fixed prices.
- Every page carries an advertising + medical disclaimer; `/methodology`, `/disclosure`
  and `/about` support E-E-A-T.
